# ShilpaKala Showcase

ShilpaKala Showcase is an Android application designed to showcase and manage traditional Indian handicrafts, specifically focusing on stone and wood carvings from artisans in regions like Shivarapatna.

## Features

- **Artwork Catalog:** Browse a collection of exquisite artworks categorized by type (e.g., Stone Idols, Wood Carving).
- **Artisan Profiles:** View detailed profiles of the master craftsmen behind the art.
- **Favorites:** Mark your favorite artworks for easy access later.
- **Dashboard:** Monitor sales and track pending orders (for artisan view).
- **Dynamic Filtering:** Filter artworks by category.
- **Local Persistence:** Data is stored locally using the Room database.

## Tech Stack

- **UI:** Jetpack Compose for a modern, declarative UI.
- **Architecture:** MVVM (Model-View-ViewModel).
- **Database:** Room for local data storage and persistence.
- **Concurrency:** Kotlin Coroutines and Flow for reactive data handling.
- **Image Loading:** Coil for asynchronous image loading.
- **Navigation:** Jetpack Compose Navigation.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ShilpaKalaShowcase.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or a physical device.
