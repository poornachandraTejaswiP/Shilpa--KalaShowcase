# 🪨 Shilpa-Kala Showcase

A modern Android application built using **Kotlin** and **Jetpack Compose** to digitally empower traditional stone and wood artisans by providing a premium digital gallery platform.

---

# 📱 About The Project

Shilpa-Kala Showcase bridges the gap between **ancient Indian craftsmanship** and **modern digital technology**. The application allows artisans to showcase handcrafted sculptures, carving processes, and cultural heritage to national and international buyers.

The project focuses on preserving traditional art forms while helping rural artisans gain digital visibility and direct customer interaction.

# 📦 Installation

## 1️⃣ Clone Repository

```bash
git clone  (https://github.com/poornachandraTejaswiP/Shilpa--KalaShowcase.git)
```

## 2️⃣ Open in Android Studio

* Open Android Studio
* Select "Open Project"
* Choose the project folder

## 3️⃣ Sync Gradle

Wait for Gradle dependencies to download.

## 4️⃣ Run Application

Connect emulator/device and click ▶ Run.
